# Glassmorphism Login Page

A simple and modern login page created using HTML and CSS.

## 🚀 Project Overview

This project is a beginner-friendly frontend UI practice project. 
It contains a glassmorphism style login card with input fields and a button.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive login card design
- Glassmorphism UI effect
- Gradient background
- Styled input fields
- Clean and simple layout
